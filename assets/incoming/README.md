# Drop models here

Put `.glb` files in a folder for what they are: `props`, `furniture`, `people`, `bikes`, `cars`, `buildings` or `guns` (for example `assets/incoming/bikes/bmx.glb`), then run `node tools/assets/check.mjs`.

Budgets, export settings and what the check does are in [docs/ASSETS.md](../../docs/ASSETS.md).
